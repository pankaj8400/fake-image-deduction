# 🛡️ ForensIQ — Deepfake & Manipulated Image Forensics

A production-grade, full-stack AI authentication platform that detects deepfakes, synthetic AI generation, facial swapping, and 2D digital tampering using a **Dual-Branch PyTorch Neural Network** paired with an autonomous **Groq LLM Diagnostic Forensic Agent** and a modern **React Dashboard**.

---

## 🌟 Key Capabilities

- **4-Class High-Accuracy Classification**:
  1. **`real`**: Authentic camera-captured photograph exhibiting organic sensor PRNU noise.
  2. **`photoshop`**: Traditional 2D digital tampering (splicing, clone stamping, content-aware fills).
  3. **`ai_generated`**: Synthesized media generated by AI diffusion models, Midjourney, DALL-E, or GANs.
  4. **`faceswap`**: Deepfake replacement of facial identities with boundary seams and PRNU noise inconsistency.
- **Dual-Branch Neural Vision Architecture**:
  - **Spatial Branch**: ConvNeXt-Tiny extracts high-level semantic representations (768-d).
  - **Frequency Branch**: 3-kernel Steganalysis Rich Model (SRM) filter bank (Laplacian, Edge, Cross-Star) isolates high-pass noise residuals (256-d).
  - **Cross-Attention Fusion**: Dynamically balances spatial vs spectral weights.
- **Groq AI Forensic Reasoning**:
  - Ingests physical forensic signals (SRM noise energy, PRNU noise variance, spatial attention) to generate an authoritative scientific explanation (`qwen/qwen3.8-27b`).
  - Automatic zero-crash fallback chain (`qwen/qwen3.8-27b` $\rightarrow$ `openai/gpt-oss-120b` $\rightarrow$ local deterministic rules engine).
- **Interactive React Frontend**:
  - Dark glassmorphism UI built with React 19, Vite 8, and Lucide icons.
  - Drag-and-drop evidence dropzone, real-time image preview, live backend connection badge, animated confidence bars, and clean neural telemetry (ViT score excluded from display).
- **Deterministic Ultra-Fast Packaging**:
  - Pinned with Astral's `uv` and [`backend/uv.lock`](backend/uv.lock) for instantaneous (2-5s) reproducible installs across any system.

## 🚀 Setup & Execution Guide (Local & Other Systems)

Follow these instructions to run this project on **any computer** (Windows, Linux, or macOS).

### Prerequisites
1. **Python**: `>= 3.10`
2. **Node.js**: `>= 18.x` (Recommended: Node 20 or 24 LTS)
3. **uv** (Recommended): Astral's Rust-based Python package manager

If `uv` is not installed on the system, install it via:
- **Windows (PowerShell)**:
  ```powershell
  powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  ```
- **Linux / macOS**:
  ```bash
  curl -LsSf https://astral.sh/uv/install.sh | sh
  ```
*(Or via existing Python pip: `pip install uv`)*

---

### Step 1: Configure & Start Backend (`FastAPI`)

1. **Navigate into the backend folder:**
   ```bash
   cd project/backend
   ```

2. **Restore all dependencies using `uv.lock` (Takes ~3 seconds):**
   ```bash
   uv sync
   ```
   > 💡 `uv sync` automatically reads `uv.lock`, provisions an isolated virtual environment (`.venv`), and installs all locked packages without version mismatches.

3. **Configure Environment Variables:**
   - Copy the template file:
     - **Windows:** `Copy-Item .env.example .env`
     - **Linux / macOS:** `cp .env.example .env`
   - Open `.env` and add your Groq API key (free from [console.groq.com/keys](https://console.groq.com/keys)):
     ```env
     GROQ_API_KEY=gsk_your_actual_key_here
     GROQ_MODEL=qwen/qwen3.8-27b
     GROQ_FALLBACK_MODEL=openai/gpt-oss-120b
     PORT=8000
     HOST=0.0.0.0
     DEBUG=False
     ```
     *(Note: If `GROQ_API_KEY` is omitted, the service runs automatically using its local deterministic rules engine without crashing).*

4. **Launch the FastAPI Server:**
   ```bash
   uv run uvicorn app.main:app --reload --reload-dir app --host 0.0.0.0 --port 8000
   ```
   - **Backend API**: `http://localhost:8000`
   - **Swagger UI**: `http://localhost:8000/docs`
   - **Health Endpoint**: `http://localhost:8000/api/health`

---

### Step 2: Start Frontend (`React + Vite`)

Open a **separate terminal window**:

1. **Navigate into the frontend folder:**
   ```bash
   cd project/frontend
   ```

2. **Install Node dependencies:**
   ```bash
   npm install
   ```

3. **Start the Vite dev server:**
   ```bash
   npm run dev
   ```
   - **React Dashboard**: `http://localhost:5173`
   - Network requests to `/api/*` automatically proxy to `http://localhost:8000`.

---

### Step 3: Optional Production Build

To have FastAPI directly serve the compiled React dashboard on port `8000` without running Vite in a separate terminal:
```bash
cd project/frontend
npm run build
```
Once built, opening `http://localhost:8000/` in your browser serves the React dashboard directly.

## 🛠️ Fallback: Running Without `uv` (Standard `pip`)

If `uv` cannot be installed on the machine, you can use standard Python virtual environments:

```bash
cd project/backend

# 1. Create and activate virtual environment
python -m venv venv
# Windows: .\venv\Scripts\Activate.ps1 | Linux/Mac: source venv/bin/activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Start server
uvicorn app.main:app --reload
```

## ❓ Troubleshooting

| Issue | Cause | Solution |
| :--- | :--- | :--- |
| **`uv: command not found`** | PATH not updated | Run `pip install uv` or restart your terminal. |
| **Groq `401 Unauthorized`** | Invalid API key | Verify key at [console.groq.com/keys](https://console.groq.com/keys); ensure it starts with `gsk_`. |
| **Groq `404 Model Not Found`** | Model ID deprecated | Set `GROQ_MODEL=qwen/qwen3.8-27b` in `backend/.env`. |
| **Port 8000 or 5173 busy** | Another process running | Specify a new port: `uv run uvicorn app.main:app --port 8080 --reload`. |
